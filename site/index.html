Overview

Most code models pass tests but write slow code. This project measures how efficient open source LLM-generated code really is — not just whether it works.

Based on ENAMEL (ICLR 2025), we evaluate 13 open source models on 161 programming problems. The result: no open source model reaches expert efficiency. The best one (Code Llama 7B) only matches expert speed on 33% of problems.

Key finding: Every open source model scores lower on efficiency than on correctness. The gap ranges from 0.01 (GPT-J) to 0.11 (CodeT5+ 16B). Passing tests doesn't mean your code is fast.

Methodology

Efficiency Score

For each problem, code is run against 4 levels of test cases (8 + 4 + 4 + 4 cases). The per-level score is: 

f = (T_i − max_m t[i,j,l,m]) / (T_i − max_m t*[i,l,m])

where T_i = α · maxl,m t*i,l,m with α = 2. Levels are combined by hardness-weighted mean with h = (3, 3, 4).

eff@k Estimator

The Rao–Blackwellized estimator over n ≥ k samples, using binomial weights over order statistics (Algorithm 1 from the paper). Theorem 1 proves unbiasedness and a variance bound of (k/n)·Var[max].

Robust Timing

Each test case runs R = 6 repeats, aggregated by the Hodges–Lehmann estimator for robustness to outliers. Candidates are executed in a sandboxed subprocess with resource limits.

Statistical Rigor

Every reported score carries a bootstrap confidence interval (10,000 resamples). No comparison is claimed without a pairwise test. The α-sweep and h-sweep are reported alongside the headline.
